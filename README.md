# Desafio Anti-Phishing Nuvme

Quiz estático para treinamento interno, com 10 cenários fictícios de phishing e segurança corporativa.

## Publicar no GitHub Pages

1. No repositório `nuvme-devops/phishing`, abra `index.html`.
2. Substitua o conteúdo pelo arquivo `index.html` deste pacote (ou envie este arquivo para a raiz do repositório).
3. Faça commit na branch `main`.
4. Vá a **Settings → Pages**.
5. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/(root)`, e salve.
6. Confira a aba **Actions** até a publicação terminar.
7. Acesse `https://nuvme-devops.github.io/phishing/`.

## Recursos

- 10 situações fictícias com mensagens corporativas realistas.
- Modo Treinamento e modo Avaliação.
- Nome e departamento opcionais.
- Pontuação, explicações e resumo copiável.
- Layout responsivo para computador e celular.

## Privacidade e limites

- Não envia e-mails, não coleta senhas e não faz requisições para servidores.
- Respostas e pontuação ficam apenas na memória da página enquanto o quiz está aberto.
- O nome e o departamento são opcionais e não são transmitidos nem armazenados.
- Não existe painel central nem relatório automático para administradores nesta versão.
- Os domínios de exemplo que não sejam `nuvme.com.br` são fictícios e servem apenas para treinamento.
- Um remetente exibido como `@nuvme.com.br` é apenas texto demonstrativo. O quiz não envia mensagens e não valida a autenticidade de e-mails reais.

## Sugestão de uso

Divulgue o link do GitHub Pages pela comunicação interna e informe que se trata de um exercício educativo. Para registrar resultados de forma centralizada, será necessário implementar um backend com controles de acesso, aviso de privacidade e política de retenção adequados.
