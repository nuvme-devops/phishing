# Desafio Anti-Phishing

Jogo educativo estático em português (Brasil), pronto para publicar no GitHub Pages.

## Conteúdo
- 10 cenários originais fictícios
- Escolha entre phishing e legítimo
- Feedback educativo após cada resposta
- Pontuação e resultado final
- Responsivo para celular e desktop
- Não coleta nem transmite respostas; tudo acontece no navegador

## Testar localmente
Abra `index.html` no navegador. Não há dependências, build ou servidor necessários.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub, por exemplo `desafio-anti-phishing`.
2. Envie o arquivo `index.html` e este `README.md` para a raiz do repositório.
3. No repositório, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O GitHub exibirá o endereço público do jogo na mesma página de Pages.

## Aplicar à equipe
- Compartilhe o link e peça que cada pessoa conclua o desafio individualmente.
- O jogo não envia pontuações para um painel central. Para recolher resultados, cada participante pode usar o botão **Copiar resultado** e enviar ao responsável.
- Para ranking automático, autenticação, armazenamento de resultados ou relatórios por equipe, será necessário adicionar um backend ou integrar um formulário corporativo.

## Segurança e uso
- Todos os domínios, pessoas e mensagens são fictícios e usam `.example`.
- Não use credenciais reais, não conecte páginas falsas e não envie e-mails de simulação sem autorização e planejamento.
- Use como treinamento educativo, sem punição individual.
